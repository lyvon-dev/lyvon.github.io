# 🌐 LYVON | Plataforma Digital

Bem-vindo ao repositório oficial da **LYVON**, uma plataforma web moderna focada em interfaces corporativas, dashboards e experiências digitais de alto desempenho.

---

## 🚀 Sobre o projeto

Este repositório contém um conjunto de páginas e sistemas desenvolvidos para compor uma plataforma digital completa, incluindo:

- Landing page de conversão
- Dashboard de análise
- Portal corporativo
- Sistema de autenticação
- Integração com QR Code PIX

---

## 📁 Estrutura do projeto

- `index.html` → Página principal do site
- `landing-page-conversao-2.html` → Página de vendas e conversão
- `dashboard-analytics-2.html` → Painel de análise e métricas
- `portal-corporativo-2.html` → Área institucional da empresa
- `plataforma-autenticacao-2.html` → Login e autenticação de usuários
- `qrcode-pix.jpg` → Sistema de pagamento via PIX

---

## ⚙️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- GitHub Pages (deploy)
- Design UI moderno

---

## 🎯 Objetivo

Criar uma plataforma digital escalável, com foco em performance, conversão e experiência do usuário, simulando sistemas de nível corporativo e startup global.
